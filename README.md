## Overview

**CrewAI** is a multi-agent orchestration framework focused on high-performance agent engineering. Unlike giant prompts where we ask a single model to act on several different fronts, CrewAI lets you structure a team ("crew") where each agent has a well-defined role (`role`), goal (`goal`), and backstory (`backstory`).

In this project:
- We manage the virtual environment and dependencies using **`uv`** (a fast Python package manager).
- We built independent scripts based on the examples shown in the Real Python tutorial.
- We use **Google Gemini** models (`gemini-2.5-flash` and `gemini-2.5-pro`) as the engines behind the cognitive tasks.
- We ensure code quality and formatting via **Ruff**, integrated into `Makefile` commands.

## Project Structure

The scripts in the `src/` folder illustrate the gradual increase in complexity of using CrewAI:

1. **`src/single_agent.py`**:
   - Creates a single agent (`Travel Advisor`) tasked with suggesting budget-friendly destinations in Southeast Asia.
   - Ideal for understanding the basic anatomy of an agent (`Agent`), a task (`Task`), and kicking off a crew (`Crew`).

2. **`src/research_and_writer_crew.py`**:
   - Connects two agents working as a team: a Senior Research Analyst (`Senior Research Analyst`) and a Content Writer (`Content Writer`).
   - Shows the default behavior of the sequential pipeline, where the output generated by research is automatically passed as input to the writing task.

3. **`src/explicit_context.py`**:
   - Explains the use of the `context` parameter on `Task` objects.
   - Demonstrates how to explicitly specify that a task depends on results generated by specific earlier tasks, which is essential for more complex or non-linear flows.

4. **`src/agent_with_tool.py`**:
   - Equips the research agent with tools (`tools`).
   - Uses the `ScrapeWebsiteTool` tool to perform live scraping of [python.org/downloads](https://www.python.org/downloads/) and return the latest stable Python release version and date. The output feeds the writer (`Tech Blogger`), who creates a concise announcement.

## Prerequisites

To run the project locally, you'll need:
- **Python 3.12** or higher.
- **`uv`** installed on your machine. If you don't have it, you can install it following the [official instructions](https://github.com/astral-sh/uv).
- A Gemini API key, which can be generated for free at [Google AI Studio](https://aistudio.google.com/).

---

## Installation and Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/carvalhocaio/crewai-python
   cd crewai-python
   ```

2. **Install the dependencies and create the virtual environment:**
   ```bash
   uv sync
   ```

3. **Set up the environment variables:**
   Create a `.env` file in the project root (or edit the existing one) and add your Gemini API key:
   ```env
   GEMINI_API_KEY="your_gemini_key_here"
   ```

## Key CrewAI Concepts

- **Role, Goal & Backstory**: Form the agent's "identity". The more specific the details provided here, the more coherent and realistic the LLM's performance in that role.
- **Expected Output**: Every task (`Task`) requires defining an expected output. This helps calibrate the result's accuracy much more reliably.
- **Context**: Lets you feed a task with the exact outputs of other, earlier tasks in the graph, ensuring the information flow makes logical sense.
- **Tools**: Extend agents' capabilities, turning them from mere "static text boxes" into agents capable of reading web pages, querying databases, or operating third-party APIs.
